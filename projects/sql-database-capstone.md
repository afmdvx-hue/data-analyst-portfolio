## Overview

Completed as part of the IBM Database and SQL for Data Science with Python programme, this project focused on working with real-world messy data stored in relational tables.

## Process

1. **Explore** — inspected schema, identified primary keys, and mapped relationships between tables
2. **Query** — wrote joins, aggregations, and filters to answer defined business questions
3. **Clean** — handled nulls, inconsistent categories, and duplicate records
4. **Analyse in Python** — exported results and used Pandas for further exploration

## Key SQL techniques

- `JOIN` across multiple tables for a single source of truth
- `GROUP BY` with conditional aggregates
- Subqueries for cohort-style filtering
- Basic window functions for ranking and trends

## Outcome

Delivered a structured analysis report with reproducible queries — demonstrating the foundation I bring to analyst roles requiring SQL and Python together.
