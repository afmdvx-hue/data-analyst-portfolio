## Problem

Operations teams need a single view of **commercial performance**, **landed costs**, **supplier reliability**, and **quality risk** across SKUs — not scattered spreadsheets. This project builds a reproducible analytics module that turns raw supply-chain records into executive-ready KPIs and stakeholder charts.

> **Methodology demo:** The Kaggle dataset contains **100 SKUs** — ideal for showing a complete analyst workflow (Python + SQL + charts), not for enterprise-scale inference. The pipeline structure scales to larger procurement or ERP exports.

## Data sources

- **[Kaggle: Supply Chain Analysis](https://www.kaggle.com/datasets/harshsingh2209/supply-chain-analysis)** (CC0-1.0) — 100 SKUs across haircare, skincare, and cosmetics
- Fields include price, revenue, stock, lead times, shipping carriers, manufacturing costs, defect rates, routes, and Indian distribution hubs (Mumbai, Kolkata, Chennai, Bangalore, Delhi)
- Cached locally at `data/supply-chain/supply_chain_data.csv` via `npm run fetch:supply-chain`

## Approach

- **Modular pipeline** — `load_data` → `clean_data` → KPIs, supplier scorecard, product & logistics summaries (`content/code/supply_chain_analysis.py`)
- **Derived fields** — margin %, unit cost, on-time flag, quality-risk flag for filterable reporting
- **Supplier scorecard** — aggregates lead time, defect rate, on-time %, and revenue per supplier
- **Reproducible charts** — nine Matplotlib exports at 150 DPI for portfolio and PDF reports
- **Kaggle integration** — `fetch_supply_chain.py` for one-command dataset refresh

## SQL analysis

Data is loaded into **`data/portfolio.db`** (`supply_chain_skus` table). Run `npm run db:build` after fetching the CSV.

Full query pack: `content/code/supply_chain_queries.sql`

```sql
-- Supplier ranking (quality + lead time)
SELECT "Supplier name",
       ROUND(AVG("Defect rates"), 2) AS avg_defect_pct,
       ROUND(AVG("Lead time"), 1) AS avg_lead_days,
       ROUND(SUM("Revenue generated"), 2) AS total_revenue
FROM supply_chain_skus
GROUP BY "Supplier name"
ORDER BY avg_defect_pct DESC;
```

Demonstrates **GROUP BY**, **conditional aggregates**, and **ranking queries** expected in junior analyst interviews.

**Live SQL results:** [View query output on /sql](/sql#supply-chain) (regenerate with `npm run sql:report`).
