WHEN GIT ASKS YOU TO SIGN IN
----------------------------
  - A browser window may open — sign in to GitHub there, OR
  - Username: afmdvx-hue
  - Password: use a Personal Access Token (NOT your normal password)

  Create a token:
    GitHub → Settings → Developer settings → Personal access tokens
    → Generate new token (classic) → tick "repo" → copy the token
    → paste it when cmd asks for a password


IF PUSH FAILS — "rejected" or "fetch first"
-------------------------------------------
  Your GitHub repo probably has a README. Easiest fix:
    Delete the repo on GitHub → create a new EMPTY repo → run git push again.

  Or run these two lines in cmd:

git pull origin main --allow-unrelated-histories

git push -u origin main
